# T2T-CAM-exchange-CPN-Model
This repository contains a Coloured Petri Net (CPN) model developed using CPN IDE for simulation-based dependability and temporal safety analysis of Train-to-Train (T2T) communication in Virtual Coupling.
The model represents the exchange of Cooperative Awareness Messages (CAMs) between a Master Train (MT) and a Slave Train (ST), including message transmission, reception, loss, and retransmission.
The CPN model was originally presented in the conference paper at the International Conference on Reliability, Safety, and Security of Railway Systems (6th RSSRail).
https://doi.org/10.1007/978-3-032-10762-6_13

The same model is used in the extended journal study submitted to Formal Aspects of Computing, where the analysis is extended to temporal communication safety properties, including bounded message delivery delay and bounded inter-reception gap.
Both studies use the same underlying CPN model, while the journal extension provides additional safety-oriented analysis and simulation results.
